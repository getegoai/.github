# EgoLabs

**Personal AI, built in the open.**

We are building **Ego**: a personal AI system that helps people understand more and do more, while keeping control of their data, permissions, and long-term context.

We are starting with **EgoLink**, a wearable connection to the physical world, and **EgoBase**, a local foundation for personal data and coordinated action.

This is an early project. We are opening the direction, the work, and the decisions as we build. Expect working experiments, unfinished features, bugs, and changes of mind.

| Project | Start here |
| --- | --- |
| [Ego](https://github.com/getegoai/ego) | Vision, product direction, system relationships, and roadmap |
| [EgoLink](https://github.com/getegoai/egolink) | Wearable hardware, firmware, services, and the path from prototype to product |
| EgoBase | Local data and coordination; starts within the [Ego project](https://github.com/getegoai/ego) |

**Join the work:** read the roadmap, open an issue, improve the documentation, test an interface, or send a pull request. English and Chinese contributions are welcome. We will develop the published parts here, so community contributions can become part of the actual product.

**EgoLabs：公开构建由个人掌控的 AI。**

Ego 希望成为持续扩展个人认知与行动能力的 AI 伙伴。我们从 EgoLink 随身感知与通信设备、EgoBase 本地数据与协作基础逐步实现。

项目仍在早期。先公开愿景、产品定义和路线，再持续提交真实实现、问题、取舍和实验结果。欢迎通过 Issue 和 PR 参与实际产品研发。
